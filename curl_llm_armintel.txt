Пример curl-запроса к llm.armintel.ru
========================================

База: OpenAI-совместимый API (чат-эндпоинт /api/v1/chat/completions).


1) Проверить доступность и список моделей

2) Чат-запрос (подробный пример)
--------------------------------
curl -s https://llm.armintel.ru/api/v1/chat/completions \
  -H "Authorization: Bearer токен" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "DeepSeek-V4-Flash-Vision-Exp",
    "messages": [
      {"role": "system", "content": "Ты — ассистент по инфраструктуре."},
      {"role": "user",   "content": "Коротко объясни, что такое LSB-стеганография."}
    ],
    "temperature": 0.7,
    "max_tokens": 512,
    "stream": false
  }'

Параметры:
  model        — id модели из /v1/models (см. список ниже)
  messages     — история: system / user / assistant
  temperature  — креативность (0..2), ниже = детерминированнее
  max_tokens   — лимит длины ответа
  stream       — true → ответ по SSE потоком (построчно)
